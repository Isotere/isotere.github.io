# Шрифты сайта

Шрифты размещены локально в формате WOFF2. Браузер получает их с того же сайта; обращения к Google Fonts для отображения текста нет. Файлы разделены на наборы символов через `unicode-range`, поэтому загружаются только нужные наборы.

| Семейство | Использование | Начертания | Лицензия |
| --- | --- | --- | --- |
| [Balsamiq Sans](https://fonts.google.com/specimen/Balsamiq+Sans) | Заголовки, вес 700 | Прямое жирное начертание | [OFL 1.1](balsamiq-sans/OFL.txt) |
| [Nunito](https://fonts.google.com/specimen/Nunito) | Основной текст, вес 400 | Прямое и курсив, переменный вес 400–800 | [OFL 1.1](nunito/OFL.txt) |
| [Victor Mono](https://rubjo.github.io/victor-mono/) | Цитаты курсивом, код прямым начертанием | Прямое и курсив, переменный вес 100–700 | [OFL 1.1](victor-mono/OFL.txt) |

Загруженные файлы поддерживают кириллицу и латиницу, включая расширенные наборы. Balsamiq Sans сохраняет характер письма печатными буквами, Nunito задаёт ровный округлый рисунок основного текста. Для Nunito подключены реальные курсивные и жирные начертания. Математические шрифты MathJax настраиваются отдельно и этими стилями не заменяются.

Исходные WOFF2 получены через официальный Google Fonts CSS API 31 октября 2026 года; содержимое файлов не менялось. URL каждого файла, его размер и SHA-256 сохранены в [sources.json](sources.json). Оригинальные тексты лицензий и copyright находятся в папках соответствующих семейств. Лицензии разрешают использование этих шрифтов в блоге, в том числе коммерческом; при распространении файлов сохраняй лицензии и сведения об авторах.

Объявления `@font-face` находятся в `docs/stylesheets/fonts.css`, назначение шрифтов элементам - в `docs/stylesheets/site.css`. Встроенная загрузка Google Fonts отключена параметром `font = false` в `zensical.toml`.
