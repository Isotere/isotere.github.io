# Зачем я изучаю финансы через код

Я работаю разработчиком на Go. Хочу разобраться в математике, финансах и инвестировании, освоить Python и постепенно перейти к исследованию алгоритмических стратегий. Этот блог будет сопровождать моё обучение.

## Откуда я начинаю

С кодом и организацией данных мне поможет опыт разработки. А в финансах и математике начну с определений и задач, затем проверю расчёты в программе.

Перед публикацией дополню этот раздел конкретными примерами своих текущих знаний и пробелов.

## Первый учебный вопрос

Начну с накоплений при постоянной ставке. В простейшем примере нет пополнений, издержек и инфляции. После каждого периода проценты остаются на счёте:

$$
B_n=P(1+r)^n,
$$

где $P$ - начальная сумма, $r$ - ставка за один период, $n$ - число периодов.

При начальной сумме 1000 единиц и ставке 10% за период через два периода модель даёт:

$$
B_2=1000\cdot1{,}1^2=1210.
$$

Это вычисление для заданных условий. Постоянная ставка служит допущением модели.

## Как я проверю расчёт

Сравню формулу с последовательным начислением процентов и ручным примером. Для начала расчёт можно записать так:

```python
from decimal import Decimal

principal = Decimal("1000")
rate = Decimal("0.10")
balance = principal * (1 + rate) ** 2
print(f"{balance:.2f}")
```

Ожидаемый результат - `1210.00`. В учебной программе отдельно проверю нулевую ставку, один период и несколько последовательных начислений. Затем добавлю пополнения и задам порядок денежных операций.
